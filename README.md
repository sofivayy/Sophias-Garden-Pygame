Станьте мастером домашнего сада в этом уютном симуляторе!

Ваша задача — превратить пустые полки в процветающую оранжерею. Покупайте семена, следите за поливом и собирайте урожай, чтобы открыть самые редкие виды цветов.

Особенности игры:

5 видов растений: от простых ромашек до экзотических золотых орхидей.

Интерактивный уход: уникальная механика «идеального полива» для ускорения роста.

Экономика: зарабатывайте монеты на продаже цветов и развивайте свой сад.

Атмосфера: приятная графика, звуки и система личных рекордов.

Сможете ли вы вырастить идеальный сад, не погубив ни одного ростка?

🛠 Технические требования
Для запуска игры вам понадобятся:

Python 3.8 или выше.

Библиотека Pygame: используется для отрисовки графики и обработки звука.

Экран: разрешение не менее 1000x700 пикселей.

📥 Установка и запуск
Клонируйте репозиторий или скачайте его как ZIP-архив:

Bash
git clone [ССЫЛКА_НА_РЕПОЗИТОРИЙ](https://github.com/sofivayy/Sophias-Garden-Pygame)
Установите библиотеку Pygame, если она еще не установлена:

Bash
pip install pygame
Перейдите в папку проекта:

Bash
cd Sophias-Garden
Запустите игру:

Bash
python main.py
